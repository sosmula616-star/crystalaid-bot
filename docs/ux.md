# Поведение интерфейса

- **Вход.** Activity сама входит через Discord при открытии. Пока идёт вход, виден логотип; при сбое экран с причиной и кнопкой «Повторить» (если повтор имеет смысл). Нет роли саппорта: экран «Нет доступа» без повтора.
- **Разделы.** Видны только разделы уровня и прав пользователя; это удобство, доступ проверяет сервер. Раздел грузится лениво, пока грузится виден скелет. Сбой одного раздела не ломает остальные: ошибка с кнопкой повтора, повтор загружает раздел заново. Если сервер отвечает «не авторизован» уже после повторного входа, показывается экран ошибки входа.
- **Фокус.** После выбора раздела фокус переходит на заголовок. Выбор раздела в панели «Ещё» закрывает её и тоже переносит фокус на заголовок. Окна и панели возвращают фокус на кнопку, которая их открыла. Есть ссылка «Перейти к содержимому».
- **Язык.** Берётся сохранённый выбор, иначе язык Discord, иначе язык браузера. Смена в Настройках сохраняется.
- **Тема.** Выбирается в Настройках, применяется сразу и хранится в браузере. Недоступные темы заблокированы с причиной.
- **Режим поверх чата.** Событие Discord о режиме «поверх чата» включает компактный вид: заголовок и главное действие раздела. Разделы при этом не выгружаются и сохраняют состояние. Событие обычного режима возвращает обычный вид. SDK не отдаёт текущий режим при запуске, поэтому окно, начавшееся поверх чата, становится компактным по первому событию или по ширине меньше 320 px.
- **Движение.** При `prefers-reduced-motion` анимации выключены, загрузка кнопки показывается неподвижным кольцом.
