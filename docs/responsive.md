# Адаптивность

Раскладка выбирается по ширине самой оболочки (container queries), а не окна, поэтому она верна и когда Discord меняет размер панели Activity.

| Режим | Ширина | Вид |
|---|---|---|
| Компактный | меньше 320 px или окно поверх чата | заголовок и одно главное действие |
| Узкий | 320–719 px | нижняя панель из первых четырёх разделов и «Ещё» (остальные в Drawer) |
| Средний | 720–1279 px | боковая панель иконками с подсказками |
| Широкий | 1280–1919 px | боковая панель с подписями |
| Очень широкий | от 1920 px | то же, содержимое не шире 1440 px по центру |

Высота задаётся через `dvh`, учитываются `safe-area-inset`; уведомления поднимаются над нижней панелью (`--toast-bottom-offset`). Таблица до 720 px показывает карточки. Длинные имена (до 40 символов) переносятся или обрезаются с многоточием, страница не прокручивается вбок.

## Что проверяет браузерный тест

`pnpm --dir apps/activity run test:e2e` (Chromium, Playwright):

- 15 размеров 320×568 … 3440×1440 для `SUPPORT` и `ADMIN`: нет горизонтальной прокрутки, элементы панели внутри окна, до последнего раздела можно дойти через навигацию, нет ошибок консоли; то же для `ADMIN` с `?name=long`.
- Масштаб текста 200 % (размер шрифта корня, проверяется что текст вырос вдвое) на 390×844 и 1280×720 и масштаб страницы 200 % (окно вдвое уже).
- Изменение размера окна 1280 → 390 → 1280 сохраняет раздел; событие режима поверх чата включает и выключает компактный вид.
- axe на Обзоре, Настройках и экране `NOT_STAFF` (390 и 1440, с проверкой контраста).
- Витрина: порядок слоёв (Select в Modal, Dropdown и Tooltip в Drawer, Toast над Modal), таблица карточками на 390 px, `prefers-reduced-motion`.
- Повтор после сбоя загрузки раздела.
- Сборка (режим production): в файлах нет `/kit` и подставного режима, внешних запросов нет, кроме доменов Discord из SDK (строки библиотек перечислены ниже).

Снимки экрана сохраняются в `apps/activity/e2e/screenshots` (в git не попадают).

## Границы проверок

- Размер текста 200 % проверяется через размер шрифта корня; размеры шрифта в токенах заданы в `rem` (при корне 16 px они прежние), отступы остаются в px. Тест сначала проверяет, что вычисленный размер заголовка действительно вырос вдвое, и затем смотрит Обзор и Настройки с открытым списком языка на 390×844 и 1280×720.
- Каждая проверка размера ждёт реального содержимого раздела, а не скелета загрузки.
- Повтор после сбоя загрузки раздела проверен только на dev-сервере: в производственной сборке нет подставного режима, войти без настоящего Discord нельзя (см. [testing.md](testing.md)).
- Внешние адреса в сборке: кроме доменов Discord в файлах есть строки `www.w3.org`, `json-schema.org`, `react.dev`, `github.com`, `localhost`. Это строки внутри библиотек, во время работы они не запрашиваются.
